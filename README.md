プラグイン管理リストプラグイン
制作者:RNSK

概要
プラグインを管理できるツールウィンドウを追加するプラグインです

使用方法
画面左上にあるツールから「プラグイン管理リスト」を選択肢使用できます
プラグイン名左のボタンをクリック、
またはシフトまたはコントロールで一括選択し無効化/有効化、削除ができます

変更内容
ー追加ー
YMM4Hubの情報追加に合わせてリストで表示される情報を追加
並び替えの種類を追加
ー削除ー
名前変更ボタンを削除
